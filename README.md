# 단추의 한밤중 소동 ✧

**한 줄의 미션, 디테일한 2D 장면, 조금 엉뚱한 정답.**

테스트: https://strange-cafe-suming.silkyfrost33.chatgpt.site

‘브레인퍼즐’처럼 장면을 관찰하고 물건을 터치·이동해 상황을 해결하는 30단계 퍼즐입니다. 하나의 주인공인 고양이 인형 단추가 잃어버린 별 조명을 찾아 침대 곁에 다시 켜 줍니다. 복잡한 세계관, 긴 대사, 회로·방향판 조작을 없애고 짧은 시각적 문제와 엉뚱한 상호작용에 집중했습니다.

## V4 변경

- 30단계를 ‘주변 물건 조합’ 퍼즐로 다시 설계했습니다. 젓가락+크레파스 사다리, 연필+털실+자석 낚싯대, 지우개+연필 지렛대, 블록+자 시소처럼 장면 속 물건을 합쳐 해결합니다.
- 순서 상관없는 조합 단계, 엉뚱한 조합에 대한 장면별 반응, 헷갈리게 하는 물건을 추가했습니다.
- 옮긴 물건이 목표로 날아가 합쳐지고, 틀린 곳에 놓으면 제자리로 돌아가며 흔들립니다. 단추는 순간이동 대신 점프해 이동합니다.
- 물건이 합쳐지면 그림이 바뀝니다(사다리 칸, 차오르는 물, 꽂힌 플러그 등). 저장 키가 바뀌어 V3 기록은 이어지지 않습니다.

## V3 변경

- 실시간 3D를 없애고 2D 이미지·SVG 장면으로 전환했습니다.
- 새로 제작한 섬세한 침실 배경과 바느질·털결·목도리 짜임이 보이는 단추 그림을 적용했습니다.
- 누르기, 옮기기, 옆으로 치우기만 사용합니다. 일부 장면은 여러 번 톡톡 누르면 됩니다.
- 그림 속 해로 얼음을 녹이고, 달을 그릇에 옮기는 등 장면을 활용한 기발한 해결법을 넣었습니다.
- 첫 두 단계는 작은 조작 안내를 보여 줍니다. 설치나 긴 도입 화면 없이 바로 플레이합니다.
- 지도·진행 저장·힌트·재도전 기능을 유지했습니다. 도감·여행 가방·별 점수·긴 대사는 제거했습니다.

캐릭터와 배경은 원본 디자인입니다. 기존 영화 캐릭터를 사용하지 않습니다. 5개 구간은 같은 침실 안의 진행 구간이며, 현재는 하나의 상세한 배경을 공유합니다.

## 실행

외부 라이브러리나 의존성 다운로드 없이:

```sh
python3 -m http.server 8080 --directory dist
```

브라우저에서 `http://localhost:8080`을 엽니다. 정적 호스팅의 공개 폴더는 `dist/`입니다. 모바일 터치와 마우스를 지원합니다. 장면을 직접 조작하기 어려울 때는 ‘조작 도움말 · 물건 목록’을 펼쳐 같은 동작을 버튼으로 할 수 있습니다.

## 소스

- `dist/story.js`: 한 줄 목표, 소품 배치, 30단계 규칙
- `dist/art.js`: 그라디언트·하이라이트·바느질이 있는 2D 소품
- `dist/app.js`: 2D 장면, 드래그·터치·키보드, 지도, 저장
- `dist/engine.js`: 퍼즐 조건 및 저장 복원
- `dist/art/bedroom.webp`, `dist/art/button.webp`: 새로 제작한 배경과 주인공
- `docs/story-bible.md`: 단순화한 이야기와 30단계 표
- `docs/art-direction.md`: 이미지 제작 프롬프트 및 에셋 출처

## 검증과 범위

Node.js 18 이상에서 `npm test`를 실행합니다. 30단계의 풀이·저장 복원과 실제 UI 이벤트 핸들러로 1~30단계를 연속 진행하는 검사를 포함합니다. 정적 2D 장면 합성 이미지를 렌더링해 캐릭터와 배경 배치도 확인했습니다. 실제 iPhone/Android의 브라우저·터치 검수는 추가로 필요합니다.

기록은 현재 기기의 브라우저에 저장합니다. 새로운 V3 퍼즐은 V2의 복잡한 모험과 다른 문제이므로 이전 기록을 이관하지 않습니다.
