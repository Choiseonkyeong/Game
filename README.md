# 단추와 꺼진 별빛 ✦

**고양이 인형 단추와 함께하는 30단계의 3D 이야기 퍼즐.**

테스트: https://strange-cafe-suming.silkyfrost33.chatgpt.site

기존 ‘조금 이상한 카페’ 3단계 프로토타입을 확장한 두 번째 버전입니다. 동일한 고양이 인형이 카페 → 서랍 숲 → 비 오는 골목 → 정거장 → 옥상 등대를 지나며 하나의 이야기를 완성합니다. 이 프로젝트를 위해 만든 캐릭터, 줄거리, 3D 모델을 사용합니다.

## 이번 버전

- 실제 WebGL / Three.js 기반 3D 장면: 입체 메시, 조명, 부드러운 그림자, 천 질감, 작은 대기 애니메이션
- 5챕터 × 6단계, 총 30개 플레이 가능한 에피소드
- 주인공 단추: 주황색 고양이 인형, 파란 귀 패치, 초록 목도리, 황동 방울
- 삐오·보빈·우비·제로가 차례로 등장하고 마지막 챕터에서 이야기가 합쳐짐
- 이동, 누르기, 4방향 회전, 소리 순서, 길게 누르기, 회로 토글의 6가지 상호작용
- 앞선 장면을 해결하면 다음 장면이 열리는 순차 진행
- 30개의 숨은 기억, 챕터별 기억 도감, 다시 등장하는 선물과 선율
- 클리어 / 숨은 기억 / 힌트 없이 해결로 별 3개 수집; 실패 횟수 제한 없음
- 브라우저 로컬 저장 및 오프라인 캐시

이는 실시간 3D 프로토타입이며 영화 수준의 캐릭터 제작·리깅·시네마틱 애니메이션이 완성된 버전은 아닙니다. 실제 iPhone/Android의 화면·터치·프레임 성능 검수는 추가로 필요합니다.

## 실행

저장소 루트에서:

```sh
python3 scripts/prepare-assets.py
python3 -m http.server 8080 --directory dist
```

브라우저에서 `http://localhost:8080`을 엽니다. 정적 호스팅할 때는 **dist/**를 공개 디렉터리로 사용합니다. 최초 실행 전 준비 스크립트가 공식 npm 배포본의 SHA-512를 검증해 3D 의존성을 받습니다. 이후 Three.js는 외부 CDN 호출 없이 `dist/vendor/`에서 불러옵니다.

3D 화면은 WebGL 2를 지원하는 브라우저가 필요합니다. 3D 초기화가 실패해도 물건 버튼으로 퍼즐을 진행할 수 있습니다. 휴대폰에서는 Safari / Chrome 사용을 권장합니다. HTTPS 또는 localhost에서 첫 캐싱이 완료되면 오프라인으로도 실행할 수 있습니다.

## 조작

1. 장면의 물건을 끌어 목적지에 놓거나 **물건 → 사용할 곳** 순서로 누릅니다.
2. 장면 아래의 물건 버튼으로도 같은 조작을 할 수 있습니다.
3. 방향판은 누를 때마다 0 → 1 → 2 → 3으로 돌아갑니다. 장면 안의 새겨진 표식을 참고합니다.
4. 소리 순서와 회로 패턴은 장면의 표식과 이야기에 단서가 있습니다.
5. 길게 누르는 장치는 1.3초 동안 눌러 힘을 모읍니다. 아래 전용 버튼은 키보드 Enter / Space로도 조작합니다.
6. 장면에 숨은 작은 별 또는 접근성용 ‘주변 작은 빛 살펴보기’ 버튼으로 숨은 기억을 수집합니다.
7. 모험 지도에서 열린 장면을 다시 할 수 있습니다. 이미 얻은 별·챕터 선물은 재도전해도 유지됩니다.

소리는 초기에는 꺼져 있으며 상단 ♪ 버튼으로 켤 수 있습니다. 진행은 같은 기기의 같은 브라우저에만 저장됩니다. V1 카페 퍼즐 기록은 새로운 V2 모험에 이관하지 않습니다.

## 소스와 설계

- `dist/story.js`: 30단계의 대사, 목적, 퍼즐 규칙, 숨은 이야기
- `dist/engine.js`: 불변 상태 갱신, 규칙 검증, 기록 복원, 진행 잠금
- `dist/world.js`: 원본 3D 모델, 5지역 세트, 광원, 카메라, 레이캐스트 조작
- `dist/app.js`: 지도, 도감, 보상, 저장, UI, 소리, 입력 연결
- `dist/vendor/`: Three.js 0.180.0 및 MIT 라이선스
- `docs/story-bible.md`: 세계관, 인물, 5챕터 구성, 30단계 스토리·퍼즐 표
- `test/`: 30단계 풀이, 저장 복원, 잠금, 오답 조건, 3D 물건·메시 검증

## 검증

Node.js 18 이상에서 `npm test`를 실행합니다. 브라우저 없는 로직·3D 장면 구조 검증이며 실제 GPU 화면 검수를 대체하지 않습니다.
