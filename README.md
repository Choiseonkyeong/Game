# 조금 이상한 카페 ☕

**손끝으로 풀어가는 고양이 카페의 작은 수수께끼.**

`Brain Puzzle 3: Crazy Mind`처럼 장면 속 물건을 터치하거나 옮겨 상황을 해결하는 장르에서 영감을 받은, 별도 제작한 한국어 웹 퍼즐 게임의 첫 버전입니다. 캐릭터·그림·이야기·코드는 이 프로젝트를 위해 새로 만들었습니다.

## 플레이

- 마우스로 드래그하거나 휴대폰에서 물건을 끌어다 놓습니다.
- 드래그 대신 **물건을 누르고 → 사용할 곳을 누르는 방식**도 지원합니다.
- 키보드는 Tab으로 물건을 고르고 Enter 또는 Space로 선택합니다. Esc는 선택을 취소합니다.
- 힌트를 누르면 스테이지마다 3단계의 힌트가 나옵니다. 제한 시간과 오답 횟수 제한은 없습니다.
- 오른쪽 위 메뉴에서 스테이지를 선택합니다. 모두 처음부터 선택할 수 있습니다.
- 진행 상황은 현재 브라우저의 localStorage에 저장합니다. 브라우저 데이터를 지우거나 다른 기기를 쓰면 기록이 이어지지 않습니다.

## 스테이지

| 장면 | 목표 |
| --- | --- |
| 01 · 구름 뒤에 숨은 오후 | 비를 그치게 하고 젖은 고양이를 닦기 |
| 02 · 커피 한 잔의 비밀 | 카페 머신을 켜고 커피 내리기 |
| 03 · 퇴근은 고양이의 허락부터 | 고양이의 관심을 돌리고 열쇠로 문 열기 |

## 실행

Python 3가 있는 환경에서 저장소 폴더를 열고 실행합니다.

```sh
python3 -m http.server 8080
```

컴퓨터의 브라우저에서 `http://localhost:8080`을 엽니다. 같은 Wi-Fi의 휴대폰에서는 컴퓨터의 LAN IP와 포트로 접속할 수 있습니다. `index.html`을 직접 더블클릭하면 ES 모듈 보안 제한 때문에 실행되지 않을 수 있으므로 HTTP 서버를 사용합니다.

이 저장소는 별도 빌드나 외부 라이브러리 없이 정적 호스팅할 수 있습니다. GitHub Pages를 사용할 경우 저장소 **Settings → Pages → Deploy from a branch**에서 기본 브랜치의 `/(root)`를 선택합니다. Pages는 별도로 설정해야 하며, 소스 업로드만으로 활성화되지는 않습니다.

HTTPS 또는 localhost에서 서비스 워커가 활성화됩니다. 첫 접속 시 파일 캐싱이 완료되면 이후에는 오프라인으로도 실행할 수 있습니다. 지원 브라우저에서는 홈 화면에 추가할 수 있습니다.

## 검증

Node.js 18 이상에서:

```sh
npm test
```

정답 순서, 잘못된 대상, 전원/컵 선행 조건, 고양이의 열쇠 보호 조건, 서로 다른 풀이 순서, 저장 데이터 복원을 검사합니다.

## 구성

- `index.html`, `style.css`: 한국어 UI 및 모바일 반응형 레이아웃
- `scenes.js`: 직접 그린 SVG 장면과 아이템
- `engine.js`: 스테이지 상태·정답 조건·저장 데이터 복원
- `app.js`: 터치·마우스·키보드 조작, 힌트, 스테이지 전환, 로컬 저장
- `sw.js`, `manifest.webmanifest`, `icon.svg`: 설치형 웹 앱 기초 및 오프라인 캐시
- `test/engine.test.js`: 퍼즐 로직 테스트

## 현재 범위

3개 스테이지를 담은 웹 게임 프로토타입입니다. Android/iOS 네이티브 패키지, 스토어 출시, 광고, 결제, 로그인, 서버 저장 기능은 포함하지 않습니다. 모바일 기기와 실제 브라우저에서의 조작·화면 검수는 추가로 필요합니다.
