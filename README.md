# 단추의 여행책 · 여섯 도시의 작은 단서

현대적인 숙소와 생활 공간에서 숨은 물건을 찾아 여행책을 완성하는 2D 상황 퍼즐. 서울 → 도쿄 → 타이베이 → 방콕 → 파리 → 리스본, 6개 배경에 5단계씩 총 30단계입니다.

## 플레이

- 기본 화면에는 아이템 아이콘, 반짝이는 점, 이름표가 표시되지 않습니다.
- 그림 속 이불·가방·틴·서랍·재킷을 눌러 가까이 살펴봅니다.
- 확대 화면에서 걷기/열기를 누르거나 그림을 옆으로 밀면 안쪽을 확인합니다.
- 발견한 물건을 별도로 챙겨 소지품에 넣습니다. 발견과 획득은 다릅니다.
- 소지품을 골라 그림 속 대상에 사용하거나, 두 물건을 조합합니다. 드래그도 지원합니다.
- 단추는 바닥으로 접근하며, 가구 앞면 마스크가 캐릭터를 가립니다. 침대·창가 반응도 유지했습니다.
- 기본 단서는 작은 끈 끝, 주머니, 접힌 종이처럼 자연스러운 생활 흔적입니다. 요청한 두 번째 힌트부터 조사 영역을 잠시 표시합니다.
- 소리가 필수인 문제, 시간 제한, 생명 제한은 없습니다. 진행은 기기에 저장합니다.

## 첫 장면

이불 주름의 검은 끈 → 이불 걷기 → 카메라 발견·획득 → 선반 틴 열기 → 필름 발견·획득 → 카메라와 필름 조합 → 창밖 첫 사진.

## 코드

- `dist/adventure.js`: 30단계, 실제 배경 좌표, 숨긴 장소, 행동·조합·힌트.
- `dist/play-engine.js`: 선행 행동 검증, 아이템 소비, 이동, 저장 명령 재생.
- `dist/play.js`: 보이지 않는 조사 영역, 발견 확대 화면, 소지품, 캐릭터 바닥 이동과 가림.
- `dist/travel-art`: 현대적 6개 배경, 소품·발견 장면·8포즈 단추.
- `docs/art-direction.md`: 이미지 제작 프롬프트와 저장 경로.

빌드 없는 정적 HTML/JS. `npm test`로 전체 30단계, 숨긴 물건의 획득 조건, 조합, 저장 복구, 실제 이벤트 처리 경로를 검사합니다. UI 검사는 DOM 대역을 사용하며 실제 브라우저 화면 검사와 다릅니다. 정적 장면 합성으로 첫 방의 크기·발 위치를 확인했지만, 실제 iPhone/Android 터치 및 렌더링 검수는 별도로 필요합니다.

30개 고유 배경이 아닌 6개 공간의 30단계입니다. 걷기와 8개 자세, 확대 일러스트 전환을 사용하며 영화 수준의 연속 동작이나 모든 물건의 자유로운 물리 조작은 아닙니다. 배경은 실제 예약 가능한 장소의 재현이 아닌 창작 공간입니다.

문제 구성이 바뀌었으므로 이전 온실 V5 저장은 유지하되 새 여행 V6 진행과 합치지 않습니다.


## V6.1 — 단추가 직접 조사하는 장면

단추를 이불·베개·커튼·주머니·서랍에 끌어 놓으면 해당 장소를 조사합니다. 침대로 끌면 자동으로 잠들던 동작은 조사로 교체했습니다. 물건 가까이에 놓았을 때만 동작 안내가 나타나고, 평소에는 조사 영역을 표시하지 않습니다.

이불 접힘, 베개 들림, 주머니 뒤적임, 서랍 당김, 서울 블라인드 내림 등 장소별 짧은 모션과 열린 상태를 추가했습니다. 도시는 각각 같은 배경의 조사 후 그림을 사용하며, 조사한 부분만 합성합니다. 열린 서랍의 실제 배경 일부를 잘라 확대하고 추가 확대 버튼을 제공합니다. 발견한 물건은 열린 자리에도 작게 나타나며, 챙기면 사라집니다.

베개 아래 메모, 주머니 쪽지, 빛의 변화 등 관찰은 수첩에 남습니다. 주요 퍼즐의 물건은 기존 진행 조건을 유지합니다. 모든 소품이 필수 정답은 아니며, 주변 관찰도 탐색 방향을 알려 주는 역할을 합니다. V6 저장은 그대로 이어집니다.

동작은 별도 프레임 전환·지역별 레이어·CSS 변형·8개 단추 포즈의 조합입니다. 연속 프레임의 손 애니메이션이나 실시간 천 물리 시뮬레이션은 아닙니다. UI 이벤트/진행 검사와 정적 합성 검사를 수행했으며 실제 휴대폰 브라우저의 모션·터치 검수는 별도로 필요합니다.
