# 단추의 작은 모험 · 별빛 온실

휴대폰 화면에서 장면을 직접 만지는 2D 이야기 퍼즐. 여섯 공간, 실제로 해결하고 넘어가는 30단계입니다. Brain Puzzle 3의 짧은 상황 목표와 물건의 새로운 쓰임을 발견하는 플레이를 참고하되, 윤의 온실을 다시 여는 하나의 이야기로 연결했습니다. 원작 캐릭터·미술·문제를 복제하지 않습니다.

## 플레이

- 상자를 누르면 단추가 다가가 열고, 드러난 물건을 누르면 획득합니다.
- 소지품 하나를 고른 뒤 장면을 누르거나 끌어 놓아 사용합니다.
- 소지품 두 개를 선택하고 조합하거나 하나를 다른 소지품 위로 끕니다.
- 배경을 좌우로 밀어 방을 탐색합니다. 전체 보기로 방을 확인하고 물건을 누르면 다시 확대됩니다.
- 숫자 장치에는 읽은 단서를 직접 입력합니다. 음악 퍼즐은 글로도 표시해 소리가 필수는 아닙니다.
- 단추를 침대와 창가에 옮기면 잠자기와 하늘 보기 반응을 보입니다.
- 틀린 사용은 물건을 소모하지 않습니다. 힌트는 단계별 두 번, 시간·생명 제한 없음.
- 진행은 브라우저에 저장됩니다. 완료한 단계를 다시 플레이해도 완료 기록을 유지합니다.

## 구조

`dist/adventure.js`: 30단계의 목표, 물건, 조건, 행동, 반응, 힌트.
`dist/play-engine.js`: 검증된 행동과 저장 명령 재생. 저장된 완료 플래그를 신뢰하지 않습니다.
`dist/play.js`: 장면 이동, 단추 동작, 소지품, 조합, 입력 장치, 지도.
`dist/style.css`: 100dvh 화면, 카메라 이동, 안전 영역과 오버레이 UI.
`dist/case-art`: 여섯 배경, 단추 8자세, 소품 아틀라스.

## 확인

`npm test` — 전체 30단계, 순서·도구 조건, 잘못된 입력, 조합 소모, 저장 복구, 실제 UI 이벤트 처리 검사.

실제 모바일 브라우저 렌더링 및 터치 기기 검사는 별도로 필요합니다. 자동 UI 검사는 DOM 대역을 이용하며 브라우저 화면 검사로 간주하지 않습니다.

V4의 긴 증거 카드 연결 UI는 V5에서 장면 중심 퍼즐로 교체했습니다. 이전 V4 진행은 다른 문제이므로 덮어쓰거나 억지로 변환하지 않습니다.
