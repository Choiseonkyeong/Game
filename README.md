# 단추 사건수첩 · 00:13의 편지

**따뜻한 수선집에서 벌어진 조용한 밀실 수수께끼.**

플레이: https://strange-cafe-suming.silkyfrost33.chatgpt.site

V4는 단순히 물건을 정해진 곳에 옮기는 기존 30개 미니 퍼즐을, **여섯 공간·30개 조사 목표가 연결된 하나의 추리 사건**으로 재구성한 버전입니다. 수선사 윤의 사라진 경로와 시각을, 서로 맞지 않는 증거를 대조해 밝혀냅니다.

## 이번 버전의 중심

- **관찰과 해석 분리:** 단서 원문을 기록하고, 두 증거를 선택해 추론 질문으로 연결합니다.
- **근거가 필요한 잠금:** 비밀번호를 외워도 필요한 관찰·추론을 모으지 않으면 확정되지 않습니다.
- **서로 연결되는 퍼즐:** 냉각 기록과 시간 계산, 봉인과 발자국의 모순, 시계 도면, 도구 조합, 시각 보정, 녹음의 반복, 최종 연표와 경로 검증.
- **물리적인 도구 사용:** 자석+구리선 → 자석 낚싯줄 → 환기구의 철제 걸쇠. 선택한 도구를 현장 장치에 사용합니다.
- **읽을 수 있는 아이템:** 16종의 상세한 아이템 원화, 확대 조사, 정확한 기록 원문과 표를 제공합니다.
- **다양한 단추:** 서 있기, 생각하기, 좌우 걷기, 이불 덮고 잠들기, 양손으로 빛을 가리고 하늘 보기, 돋보기 조사, 놀라기 등 8개 별도 포즈.
- **장소 반응:** 침대와 창가로 끌어 옮기거나 장소 버튼을 누르면 해당 동작을 합니다. 천문실에서 하늘을 실제로 관찰해야 얻는 증거도 있습니다.
- **밝은 통일감:** 캐릭터를 기준으로 여섯 공간과 아이템을 따뜻한 꿀빛·크림색·세이지 계열의 2D 삽화로 다시 맞췄습니다. 공포 연출이나 점프 스케어는 없습니다.

## 공간

1. 침실 — 멈춘 벽시계와 실제 정전 시각
2. 천문실 — 온전한 봉인과 발자국의 모순
3. 시계 작업실 — 만들어진 표시 시각과 서비스 통로
4. 기록실 — 서로 다른 시계 기준을 보정한 출입 기록
5. 음악실 — 편집된 종소리와 네 음의 잠금
6. 옥상 온실 — 실제 연표·이동 경로·사건의 전모

각 공간에는 서로 다른 배경 원화가 있습니다. 현재는 30개의 독립된 방이 아닌, 하나의 사건을 이루는 **6공간·30개 조사/추리 목표**입니다.

## 실행

빌드나 외부 의존성 설치 없이:

```sh
python3 -m http.server 8080 --directory dist
```

`http://localhost:8080`을 엽니다. 모든 코드·이미지는 저장소에 포함되어 있으며 외부 CDN을 사용하지 않습니다.

## 조작

- 방 안의 표시나 아래 조사 대상 버튼으로 확대 조사합니다. 조사 위치 표시는 끌 수 있습니다.
- **조사 노트**에서 증거 두 개를 선택하고 연결해 추리합니다. 이미 기록한 증거는 계속 다시 읽을 수 있습니다.
- **소지품**에서 하나를 선택한 뒤 장치를 누르면 사용합니다. 두 개를 선택하면 조합할 수 있습니다.
- 바닥을 누르면 단추가 좌우로 걸어 이동합니다. 단추를 침대나 창가로 끌어 놓으면 장소별 행동을 합니다.
- 단추를 누르면 현재 자세를 크게 볼 수 있습니다. 키보드 방향키와 장소 버튼도 지원합니다.
- 납통은 소리를 재생하거나 동등한 내용의 기록으로 확인할 수 있습니다. 시간제한·실패 횟수 제한은 없습니다.
- 힌트는 각 공간마다 세 단계로 구체화됩니다. 진행은 이 브라우저의 localStorage에 저장합니다.

## 구성

- `dist/case.js`: 사건, 공간, 증거 원문, 아이템, 추리 조건과 30개 목표
- `dist/engine.js`: 근거 검증, 아이템 조합·사용, 공간 잠금, 기록 복원
- `dist/app.js`: 이동·포즈·확대 조사·수첩·입력·소리·UI
- `dist/case-art/`: 여섯 공간, 8포즈 시트, 16아이템 시트
- `docs/case-design.md`: 논리 흐름과 검증 범위
- `docs/art-direction.md`: 최종 시각 방향 및 제작 프롬프트

## 검증과 현재 범위

Node.js 18 이상에서 `npm test`를 실행합니다. 전체 사건 풀이, 단계별 저장 복원, 근거 없는 정답의 차단, 잘못된 도구·조합, UI를 통한 전체 사건 진행, 침대/창가의 포즈 전환을 검증합니다. 정적 장면 합성도 렌더링해 배경과 단추의 배치를 확인했습니다.

이는 플레이 가능한 사건 프로토타입입니다. 실제 휴대폰의 터치·레이아웃·음향 검수와 성인 플레이어의 난이도/추론 만족도 검증은 추가로 필요합니다. 캐릭터 이동은 8개의 별도 정지 포즈와 위치 이동/가벼운 보행 효과를 조합하며, 영화 수준의 연속 프레임 애니메이션은 아닙니다.
