# CASE 01 — 00:13의 편지

## 방향

사용자가 원한 것은 복잡한 용어가 아니라, 관찰한 물건과 다른 장소의 기록을 다시 연결해 생각할 수 있는 성인용 추리였다. 하나의 장소에서 같은 물건을 옮기는 30개 미니 퍼즐을 여섯 공간·30개 조사/추리 목표의 한 사건으로 바꿨다. 그림과 표정은 따뜻하고 접근하기 편한 방향으로, 추리에는 근거의 대조가 필요하도록 구성했다.

## 확인 가능한 사실과 해석

- 벽시계의 표시 00:13은 관찰 사실이다. 그것이 실제 정전 시각이라는 것은 아직 입증되지 않은 해석이다.
- 창을 향하는 발자국은 관찰 사실이다. 그 창으로 출입했다는 주장은 봉인과 먼지 흔적으로 반박할 수 있다.
- 타각 시각과 승강기의 독립 시각은 출처가 다르다. 모든 기록에 같은 보정치를 적용하면 안 된다.
- 접합 흔적과 동일 파형의 반복은 녹음 편집의 증거다. 들린 종소리가 실시간이었다는 전제를 재검토한다.
- 마지막 편지는 정답 선언으로 끝내지 않고, 앞서 모은 물리적 경로와 독립 기록이 이를 뒷받침하는지 확인한다.

## 시간 검산

난방 정상 30°C → 관측 24°C. 제공된 실측 조건 10분마다 2°C 하강이므로 30분 경과. 고정된 조사 기준 시각 00:10에서 30분을 빼면 실제 정전은 전날 23:40.

기록실의 타각 시계는 12분 빠르다. A 00:08 → 23:56 / B 23:35 → 23:23 / C 23:52 → 23:40 / D 00:21 → 00:09. 실제 순서 BCAD. C는 카트가 운반로에 진입한 시각이다.

승강기 운행표 23:56은 별도 독립 제어기의 실제 시각이며, 카트가 옥상에서 출발한 사건이다. 카트 진입 23:40과 운반 출발 23:56을 구분한다.

최종 순서: 정전/운반로 진입 23:40 → 승강기 출발 23:56 → 뒤늦게 재생된 종소리 00:13. 벽시계 표시와 종소리는 이동 시각을 은폐하는 연출이었다.

## 30개 목표

| 공간 | 조사/추리 목표 |
| --- | --- |
| 침실 | 냉각표 / 표면 온도 / 경과 시간 / 실제 정전 시각 / 안쪽 문 |
| 천문실 | 봉인 / 발자국 / 창문 경로 검증 / 성도 / 영상 방위 잠금 |
| 작업실 | 도면 / 릴레이 / 가짜 시각 해명 / 자석 도구 조합 / 환기구 통로 |
| 기록실 | 대장 / 보정표 / 카트 진입 시각 / 기록 순서 / 음악실 출입 |
| 음악실 | 납통 접합부 / 악보 / 녹음 시각 검증 / 선율 잠금 / 온실 출입 |
| 온실 | 운행표 / 편지 / 실제 연표 / 이동 경로 / 사건 전모 |

천문실의 영상 방위 퍼즐은 도면의 좌우 대응을 묻는다. 실제 천체의 동서 지리 방향이 바뀐다고 주장하지 않는다. 정확한 기록은 확대 조사 화면의 원문으로 제공하며 생성 이미지 안의 작은 글자를 정답으로 사용하지 않는다.

## 플레이 보호

필요한 증거/선행 추론을 모아야 정답이 확정된다. 소지하지 않은 물건을 사용할 수 없고, 올바른 두 물건만 조합된다. 전체 진행은 유효한 행동 기록을 다시 실행해 복원한다. 임의로 저장된 완료 플래그만으로는 사건을 완료할 수 없다.

실제 성인 플레이테스트의 난이도와 추론 만족도는 미검증이다. 아직 하나의 완결 사건이며, 서로 다른 30개의 배경이나 30개의 개별 사건이 아니다.
