# 단추의 여행책 — 플레이 설계

윤이 남긴 미완성 여행책을 단추가 자신의 사진과 메모로 완성한다. 도시마다 하나의 생활 공간에서 머물고, 기록하고, 다음 장소로 이동한다. 초반부터 목적을 알고, 사진·메모·책이라는 같은 소재를 통해 연결된다.

## 발견과 공간

월드에는 아이템 그림을 표시하지 않는다. 배경 그림의 실제 가구에 투명 조사 영역을 맞춘다. 숨긴 물건은 부모 장소를 열거나 회수하는 행동을 완료해야 보이며, 확대 화면에서 별도로 챙긴다. 소지품의 그림은 획득 후에만 나타난다.

지역별 배경을 눈으로 확인한 뒤 roomAreas를 실제 위치로 조정했다. 방 화면과 물건/단추는 같은 이미지 좌표를 사용한다. 바닥 접근 y=90, 배경과 같은 크기의 전경 마스크로 가구의 가림을 전달한다. 이불을 걷거나 서랍을 여는 동작은 확대 장면의 닫힘/열림 일러스트 전환으로 구현했다.

## 검증 범위

전체 진행과 저장 재생, 조사 전 획득 차단, 조합 실패 시 재료 유지, 30단계 UI 경로, 초기 장면 아이템 미표시, 확대 화면 밀기, 다시 방문 후 완료 기록 유지. 실제 브라우저 및 기기 검수는 미실시다. 정적 합성은 장면 크기와 캐릭터 발 위치를 보는 보조 검사다.


## 직접 조사와 관찰 (V6.1)

`world.js`가 각 방의 생활 소품 영역, 동작, 관찰 문장, 열린 그림의 합성 영역을 정의한다. `dropPlace`는 드롭 지점과 영역의 거리를 비교해 가장 가까운 대상을 선택한다. 단추를 침대 아래로 끌어도 이불을 살피며 자동 수면에 들어가지 않는다. 잠긴 서랍은 조사만으로 열리지 않는다.

`explore` 명령은 물건 획득·단계 완료와 분리해 장소 상태와 관찰 수첩을 저장한다. 반복 관찰은 중복 기록하지 않는다. 실제 퍼즐의 상자를 열었을 때도 같은 장소 상태를 갱신한다. 다음 단계로 넘어가면 해당 단계의 관찰은 새 장면을 위해 초기화된다. V6의 기존 명령 기록은 계속 복원된다.

서울 첫 장면의 베개 메모는 블라인드/빛을, 재킷 주머니 쪽지는 필름의 보관 장소를 가리킨다. 해법을 카드로 미리 나열하는 대신 직접 조사한 뒤 관찰을 기록한다. 서랍의 확대는 그림 속 실제 열린 서랍 위치를 사용한다.


### V6.2 첫 방 개정
이불의 직접 드래그 → 숨은 번호 보관함 → 베개 아래 쪽지 → 창빛·등불 차단 → 축광 숫자 → 카메라 → 별도 보관 필름 → 첫 사진. 정답 번호는 메모에 직접 쓰지 않는다. 동작 이름 안내와 반복 조사 팝업은 제거한다. 다른 단계의 실제 번호·순서 메모는 수첩에 기록한다.
