# 별빛 온실: 30단계 설계

## 이야기의 약속

윤이 버려진 온실을 다시 열고 싶어 단추를 초대한다. 초반부터 목적을 알리고, 공간마다 고장 난 장치를 고치며 빛과 음악을 온실에 이어 보낸다. 마지막에 윤과 이웃이 찾아와 개장한다. 실종·범인·장문의 가설 연결은 제거했다.

## 플레이 원칙

한 화면에 구체적인 목표 하나. 상자 열기 → 물건 획득 → 사용 → 장면 변화가 보인다. 설명은 짧은 반응과 필요할 때만 여는 입력 장치에 둔다. 도구는 서로 다른 그림·색·이름으로 구분한다. 같은 천에 기름을 묻혔을 때는 기름 표시와 이름이 바뀐다. 잘못된 시도는 도구를 잃지 않는다.

| 공간 | 단계 | 구성 |
|---|---|---|
| 침실 | 1–5 | 편지 서랍, 윤활 천 조합, 자석 낚시, 렌즈로 미세 글씨, 문 쐐기 |
| 관측실 | 6–10 | 먼지 아래 별 순서, 거울 반사, 렌즈 집광, 뒤집힌 번호, 회전축 윤활 |
| 작업실 | 11–15 | 톱니 회수·장착, 톱니 회전 방향, 지렛대, 접점 청소·배선, 태엽 우편함 |
| 기록실 | 16–20 | 도장 배달, 비스듬한 빛의 자국, 바람 차단, 느린 시계 보정, 문 고정·카드 |
| 음악실 | 21–25 | 태엽·레버, 선율 재현, 나팔 막힘, 악보 방향, 악보함·음악 문 |
| 온실 | 26–30 | 유리 청소, 무게 균형, 반사와 집광, 태엽과 악보, 별 조각·개장 |

여섯 배경을 사용한다. 같은 공간의 5단계는 목표·소품·장치 상태가 달라진다. 30개의 고유 배경이나 모든 오브젝트의 독립 애니메이션을 구현했다고 표현하지 않는다. 상자는 닫힘/열림 이미지, 물건 획득은 이동 효과, 단추는 8자세로 행동을 전달한다. 사람 윤은 결말 대사로 등장한다.
