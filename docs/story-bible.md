# 단추의 한밤중 소동 — V3 이야기·퍼즐 구성

## 하나의 목적

고양이 인형 단추가 잃어버린 별 조명을 찾아, 포근한 침대 옆에 다시 켠다. 처음 플레이하는 사람에게 필요한 설정은 이것뿐이다.

## 브레인퍼즐의 핵심

- 인물의 불편이나 눈앞의 문제를 한 문장으로 보여 준다.
- 장면을 직접 누르고 물건을 옮겨 즉시 반응을 확인한다.
- 일상적인 문제 사이에 그림의 해를 꺼내기·달빛을 그릇에 담기·돋보기를 치워 크기 바꾸기 같은 시각적 반전을 섞는다.
- 한 단계는 최대 두 행동으로 해결한다. 숫자 암기, 회로 조합, 길게 누르기, 긴 도입 설정을 제거했다.
- 등장인물은 단추 중심이다. 곰과 토끼는 해당 장면의 목표를 만드는 조연으로만 잠깐 등장한다.
- 실패 횟수 제한이나 대기·생명 충전은 없다. 힌트는 현재 행동의 해결법을 알려 준다.

## 30단계

| 단계 | 한 줄 미션 | 해결 방식 |
| --- | --- | --- |
| 1 | 단추에게 이불을 덮어 주세요. | 왼쪽 아래 이불을 단추에게 가져다 주세요. |
| 2 | 불을 켜 주세요. | 오른쪽의 탁상 조명을 톡 눌러 보세요. |
| 3 | 숨은 별을 찾아 주세요. | 쿠션을 잡고 옆으로 치워 보세요. → 드러난 별을 눌러 주세요. |
| 4 | 열쇠를 내려 주세요. | 풍선에는 뾰족한 물건을 대 보면 어떨까요? → 바닥에 떨어진 열쇠를 주워 주세요. |
| 5 | 문을 열어 주세요. | 문 앞의 매트 아래를 살펴봐요. → 열쇠를 문에 넣어 주세요. |
| 6 | 단추가 별에 닿게 해 주세요. | 책을 발판 위에 쌓아 높이를 더해요. → 이제 단추를 별 쪽으로 옮겨 주세요. |
| 7 | 별의 흔적을 찾아 주세요. | 걸레로 뿌연 유리판을 닦아 주세요. → 반짝이는 흔적을 눌러요. |
| 8 | 풍선을 작게 만들어 주세요. | 풍선을 터뜨리지 말고, 아래 마개를 빼 봐요. |
| 9 | 바람개비를 돌려 주세요. | 선풍기의 바람을 바람개비에 보내 주세요. |
| 10 | 얼음 속 열쇠를 꺼내 주세요. | 그림 안의 해도 꺼낼 수 있을까요? 얼음에 옮겨 봐요. → 차갑지 않은 열쇠를 주워 주세요. |
| 11 | 단추에게 물 한 잔을 주세요. | 빈 컵을 비구름 아래로 가져다 주세요. → 물을 단추에게 주세요. |
| 12 | 작은 문을 통과해 주세요. | 단추가 정말 큰 걸까요? 앞에 놓인 돋보기를 치워요. → 작아 보이는 단추를 문으로 옮겨 주세요. |
| 13 | 열차를 출발시켜 주세요. | 리본으로 끊어진 레일을 이어 봐요. → 이제 열차를 눌러 출발해요. |
| 14 | 열차가 지나가게 해 주세요. | 길을 막고 있는 상자를 옆으로 치워요. → 기다리는 열차를 눌러요. |
| 15 | 곰을 깨우지 말고 지나가요. | 방울 위에 쿠션을 덮어 소리를 막아요. → 조용해졌어요. 열차를 출발시켜요. |
| 16 | 웅덩이를 건너 주세요. | 나뭇잎을 물에 띄워 작은 배로 써 봐요. → 단추를 나뭇잎 배에 태워요. |
| 17 | 토끼에게 별을 받아 주세요. | 토끼가 좋아할 당근을 건네 봐요. → 내려놓은 별을 눌러 주세요. |
| 18 | 진짜 별을 찾아 주세요. | 오른쪽 별에 빛을 비추면 진짜 별이 반짝여요. → 환해진 별을 눌러요. |
| 19 | 단추의 목도리를 지켜 주세요. | 열린 창문을 먼저 닫아 바람을 막아요. → 목도리를 단추에게 돌려주세요. |
| 20 | 단추를 뽀송하게 해 주세요. | 먼저 우산으로 비가 떨어지는 곳을 막아요. → 이제 마른 수건으로 단추를 닦아요. |
| 21 | 높은 곳의 별을 내려 주세요. | 길쭉한 자로 별을 살짝 밀어 내려요. |
| 22 | 빈 그릇에 달을 담아 주세요. | 창밖의 달을 그릇에 끌어다 놓아 보세요. |
| 23 | 그림 속 친구를 웃게 해 주세요. | 그림을 두 번 눌러 반 바퀴 돌려요. |
| 24 | 별을 안전하게 담아 주세요. | 별 위에 유리병을 덮어 주세요. |
| 25 | 병에서 별을 꺼내 주세요. | 뚜껑이 단단해요. 유리병을 세 번 톡톡 눌러요. → 별을 살짝 주워 주세요. |
| 26 | 단추가 침대에 오르게 해 주세요. | 종이를 틈 위에 놓아 다리로 써 봐요. → 단추를 침대로 옮겨 주세요. |
| 27 | 밤에 어울리는 불빛으로 바꿔요. | 눈부신 해 위에 달을 겹쳐 부드러운 밤으로 바꿔요. |
| 28 | 선을 자르지 말고 풀어 주세요. | 가위는 필요 없어요. 아래 플러그 끝을 옆으로 빼 봐요. |
| 29 | 별 조명을 켜 주세요. | 별을 조명의 빈 자리에 넣어 주세요. → 이제 작은 스위치를 눌러요. |
| 30 | 단추를 재워 주세요. | 모험을 마친 단추에게 이불을 덮어 줘요. → 별 조명을 눌러 은은한 수면등으로 바꿔요. |

## 화면과 이야기의 절제

같은 침실 안에서 침대 아래 → 장난감 사이 → 바닥 → 창가 → 침대 곁으로 돌아오는 작은 동선을 쓴다. 5구간은 진행을 구분하는 표기이며 복잡한 별도 세계관이 아니다. 같은 상세한 배경을 공유하고 단계별 소품·표정 말풍선·목표를 바꾼다. 지도 외의 도감·가방·재화 UI는 제거했다.

## 제작 상태

30단계의 규칙과 2D 조작 구현을 완료했다. 전체 게임의 몰입도와 난이도는 실제 초보 플레이테스트로 추가 조정해야 한다. 현재 주인공은 상세한 한 개의 이미지 포즈를 공유하며, 이불·조명·소품 이동과 간단한 움직임으로 상황 변화를 표시한다. 향후 얼굴 표정과 장면별 소품 아트를 추가하면 표현을 더 풍부하게 만들 수 있다.
