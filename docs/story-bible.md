# 단추의 한밤중 소동 — V3 이야기·퍼즐 구성

## 하나의 목적

고양이 인형 단추가 잃어버린 별 조명을 찾아, 포근한 침대 옆에 다시 켠다. 처음 플레이하는 사람에게 필요한 설정은 이것뿐이다.

## 브레인퍼즐의 핵심

- 인물의 불편이나 눈앞의 문제를 한 문장으로 보여 준다.
- 장면을 직접 누르고 물건을 옮겨 즉시 반응을 확인한다.
- 일상적인 문제 사이에 그림의 해를 꺼내기·달빛을 그릇에 담기·돋보기를 치워 크기 바꾸기 같은 시각적 반전을 섞는다.
- 한 단계는 최대 네 단계, 대부분 주변 물건 2~3개를 조합해 해결한다. 순서가 상관없는 조합(사다리 발판, 소리 막기 등)은 어떤 순서로 해도 된다.
- 엉뚱한 조합에도 장면에 맞는 반응(예: 사탕을 발판으로 → “끈적끈적… 미끄러워요”)을 보여 준다.
- 등장인물은 단추 중심이다. 곰과 토끼는 해당 장면의 목표를 만드는 조연으로만 잠깐 등장한다.
- 실패 횟수 제한이나 대기·생명 충전은 없다. 힌트는 현재 행동의 해결법을 알려 준다.

## 30단계

| 단계 | 한 줄 미션 | 해결 방식 |
| --- | --- | --- |
| 1 | 단추를 따뜻하게 해 주세요. | 털양말을 단추에게 끌어다 주세요. 쏙 들어갈 크기예요! |
| 2 | 손전등을 켜 주세요. | 리모컨 뒤쪽 뚜껑을 톡 열어 보세요. → 건전지를 손전등에 넣어요. |
| 3 | 쿠션 밑의 별 조각을 꺼내요. | 지우개를 쿠션 앞에 받침으로 놓아 봐요. → 연필을 지우개 위에 걸쳐 쿠션 밑에 끼워요. → 연필 끝을 꾹! 쿠션을 눌러 보세요. → 별 조각을 주워요. |
| 4 | 사다리를 만들어 올라가요. | (크레파스를 젓가락 사이에 하나씩 끼워 발판을 만들어요.) → 단추를 침대 위 별 쪽으로 옮겨요. → 별 조각을 주워요. |
| 5 | 꽃병 속 열쇠를 꺼내요. | 구슬을 넣으면 물이 어떻게 될까요? → 열쇠를 문에 넣어요. |
| 6 | 풍선을 타고 선반에 올라요. | 풍선에 털실을 묶어 줄을 만들어요. → 풍선 줄을 단추에게 쥐여 줘요. → 별 조각을 잡아요. |
| 7 | 곰을 재우고 지나가요. | 태엽을 오르골에 끼워요. → 오르골을 톡 눌러 틀어요. → 살금살금, 단추를 문으로 옮겨요. |
| 8 | 자석 낚싯대를 만들어요. | (연필에 털실과 자석을 달아 낚싯대를 만들어요.) → 낚싯대를 어항에 드리워요. → 별 조각을 떼어 내요. |
| 9 | 웅덩이를 건너가요. | 종이를 두 번 톡톡 눌러 접어요. → 종이배를 웅덩이에 띄워요. → 단추를 배에 태워요. → 선풍기 바람을 돛에 보내요. |
| 10 | 얼음을 녹여 열쇠를 꺼내요. | 드라이어 플러그를 콘센트에 꽂아요. → 드라이어를 얼음에 대요. → 열쇠를 주워요. |
| 11 | 토끼와 별을 바꿔요. | 화분에 물을 줘 봐요. → 당근을 토끼에게 건네요. → 별 조각을 주워요. |
| 12 | 달빛으로 터널을 비춰요. | 창밖 달빛을 거울로 터널에 반사해요. → 별 조각을 주워요. |
| 13 | 다리를 놓아 기차를 보내요. | 블록을 틈 가운데 받침 기둥으로 세워요. → 나무 자를 기둥 위에 얹어요. → 기차를 출발시켜요. |
| 14 | 곰을 깨우지 말고 지나가요. | (방울 소리와 발소리, 둘 다 막아야 해요.) → 살금살금 문으로! |
| 15 | 웅덩이를 말려 별을 주워요. | 스펀지로 물을 빨아들여요. → 별 조각을 주워요. |
| 16 | 빛나는 진짜 별을 골라요. | 불을 끄면 진짜 별만 빛나요. → 반짝이는 별을 골라요. |
| 17 | 목도리를 되찾아요. | 창문을 닫아 바람부터 막아요. → 옷걸이 고리로 목도리를 걸어 당겨요. → 목도리를 단추에게 둘러 줘요. |
| 18 | 서랍을 열어 별을 찾아요. | 테이프를 서랍 앞에 붙여요. → 실패를 테이프 위에 붙여 손잡이로! → 손잡이를 당겨요. → 별 조각을 꺼내요. |
| 19 | 책으로 계단을 쌓아요. | (책을 창틀 아래에 차곡차곡 쌓아요.) → 단추를 계단 위로! → 별 조각을 주워요. |
| 20 | 우산으로 별을 끌어와요. | 자로 높은 빗장을 밀어요. → 우산 손잡이를 갈고리처럼! → 별 조각을 주워요. |
| 21 | 그릇에 달을 담아요. | 그릇에 물을 부어 봐요. → 달이 뜬 그릇을 단추에게! |
| 22 | 그림 속 친구를 웃게 해 주세요. | 그림을 두 번 눌러 반 바퀴 돌려요. |
| 23 | 별을 병 속으로 유인해요. | 달콤한 별사탕을 병에 넣어요. → 들어가는 순간 뚜껑을 탁! |
| 24 | 병뚜껑을 열어요. | 미끄럽지 않게 고무장갑을 끼워요. → 뚜껑을 세 번 돌려요. → 별 조각을 꺼내요. |
| 25 | 시소로 침대에 올라가요. | 나무 자를 블록 위에 얹어요. → 단추를 시소 한쪽 끝에! → 반대쪽 끝에 책을 쿵! |
| 26 | 은은하고 조용한 방으로 만들어요. | (불빛도, 시계 소리도 부드럽게 바꿔요.) |
| 27 | 선을 자르지 말고 풀어 주세요. | 가위는 필요 없어요. 아래 플러그 끝을 옆으로 빼 봐요. |
| 28 | 멀티탭으로 전선을 이어요. | 멀티탭을 벽 콘센트에 먼저 꽂아요. → 조명 플러그를 멀티탭에! |
| 29 | 별 조명을 켜 주세요. | 별 조각을 조명의 빈 자리에 넣어요. → 이제 작은 스위치를 눌러요. |
| 30 | 단추를 재워 주세요. | 모험을 마친 단추에게 이불을 덮어 줘요. → 별 조명을 눌러 은은한 수면등으로 바꿔요. |

## 화면과 이야기의 절제

같은 침실 안에서 침대 아래 → 장난감 사이 → 바닥 → 창가 → 침대 곁으로 돌아오는 작은 동선을 쓴다. 5구간은 진행을 구분하는 표기이며 복잡한 별도 세계관이 아니다. 같은 상세한 배경을 공유하고 단계별 소품·표정 말풍선·목표를 바꾼다. 지도 외의 도감·가방·재화 UI는 제거했다.

## 제작 상태

30단계의 규칙과 2D 조작 구현을 완료했다. 전체 게임의 몰입도와 난이도는 실제 초보 플레이테스트로 추가 조정해야 한다. 현재 주인공은 상세한 한 개의 이미지 포즈를 공유하며, 이불·조명·소품 이동과 간단한 움직임으로 상황 변화를 표시한다. 향후 얼굴 표정과 장면별 소품 아트를 추가하면 표현을 더 풍부하게 만들 수 있다.
