# 포근섬 · 구글 플레이 출시 준비

상태: **포장 설정까지 준비됨, 앱 빌드·등록은 아직 안 함.** 이 실행 환경에는 Android SDK가 없어 APK/AAB를 만들 수 없습니다. 아래 단계 중 표시된 부분은 저장소 소유자(개발자 계정 보유자)가 직접 해야 합니다.

## 출시 전에 반드시 끝나야 하는 것
1. **아트 교체** — 규격 문서의 최소 세트(캐릭터 71장 + 섬 배경 + 소품). 지금 화면은 임시 그림입니다.
2. **아이콘·스토어 그래픽** — 임시 아이콘을 실제 디자인으로 교체. 대표 이미지 1024×500, 스크린샷 2장 이상.
3. **개인정보처리방침의 운영자 이름·이메일 기입.**
4. **실제 휴대폰 검수** — 저사양 안드로이드 1대 이상에서 터치, 프레임, 저장/복원.
5. **앱 ID 확정** — 임시 `kr.pogeun.island`. 한 번 올리면 바꿀 수 없습니다.

## 빌드 (Android Studio가 설치된 PC에서)
```bash
cd android-app
npm install
npx cap add android        # 처음 한 번
npm run sync               # dist/island → www 복사 후 안드로이드 프로젝트에 반영
npm run open               # Android Studio 열기
```
Android Studio: Build → Generate Signed Bundle → **Android App Bundle(.aab)** → 업로드 키 새로 만들기.
- 업로드 키(.jks)와 비밀번호는 **저장소에 올리지 말고** 안전한 곳에 백업(분실 시 업데이트 불가). `.gitignore`에 제외되어 있습니다.
- 대상 SDK는 현재 플레이 요구 버전(Android Studio 최신 템플릿 기본값)을 사용합니다.

## 플레이 콘솔 (소유자 직접)
1. 개발자 계정 등록(1회 25달러, 본인 인증). 2023년 이후 신규 개인 계정은 **테스터 12명 이상 · 14일 비공개 테스트**를 거쳐야 프로덕션 출시 신청이 가능합니다.
2. 앱 만들기 → 기본 언어 한국어, 게임, 무료.
3. 앱 콘텐츠
   - 개인정보처리방침 URL: 위 공개 URL
   - 광고: 없음
   - 데이터 보안: 수집·공유 데이터 없음(기기 내 저장만)
   - 콘텐츠 등급 설문: 폭력·도박 없음 → 전체이용가 예상
   - 타깃 연령: **13세 이상 권장.** 아동(13세 미만)을 대상에 포함하면 가족 정책 추가 심사 대상이 됩니다.
4. 스토어 등록정보 초안
   - 앱 이름: 포근섬 · 나의 작은 섬
   - 짧은 설명(80자): 나만의 아바타를 꾸미고, 꽃을 심고, 고양이 모모와 작은 섬을 가꾸는 힐링 게임
   - 자세한 설명: 옷장에서 매일 다른 코디를 고르고, 섬을 산책하며 씨앗을 심고 물을 주세요. 사과를 따고, 벤치에 앉아 쉬고, 가구를 원하는 자리에 놓아 나만의 섬을 꾸밀 수 있어요. 꾸민 모습은 기념사진으로 남길 수 있어요. 광고·결제·로그인 없이 기기에 자동 저장됩니다.
5. 비공개 테스트 트랙에 AAB 업로드 → 테스터 초대 → 14일 후 프로덕션 신청.

## 주의
- 특정 게임(퍼피레드·메이플스토리 등)의 캐릭터·이름·그림·효과음을 사용하면 심사 거절 및 권리 침해 위험이 있습니다. 모든 아트는 직접 만든 것이어야 합니다.
- 기능이 너무 적거나 웹사이트를 감싼 것처럼 보이면 "최소 기능" 정책으로 거절될 수 있습니다. 오프라인 실행·저장·사진 저장은 들어가 있으나, 콘텐츠 양(옷·가구·이벤트)을 늘리는 것이 안전합니다.
