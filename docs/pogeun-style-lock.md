# 포근섬 절대 그래픽·콘텐츠 기준

사용자 확정 기준 (2026-10-27). 포근섬의 모든 신규/수정 화면·UI·캐릭터·배경·오브젝트에 적용한다. 기존 승인 원화를 보존하고 요청한 부분만 변경한다.

- 따뜻한 저채도 픽셀/2D 일러스트 혼합, 부드러운 다크 브라운 외곽선. 실사/고딕/하이폴리3D/형광/고채도원색/차가운 메탈릭 금지.
- 작은 아이소메트릭 단일 플로팅 아일랜드, 둥근 수풀·풀밭·돌·아기자기한 나무집. 파스텔 핑크/라벤더/하늘색 그라데이션, 둥근 솜사탕 구름·은은한 태양. 브리지/분리된 서브섬을 임의 추가하지 않는다.
- 2~2.5등신 SD, 큰 눈·둥근 얼굴, 기존 얼굴·헤어·비율·선·질감 보존. 기본 흰티/연청반바지/흰스니커즈. 남녀 동일 질감. 정면/후면/양측면 유지.
- 가로 화면. 좌상단 프로필/닉네임/레벨·돌봄 경험 바, 우상단 기존 조개·하트/설정/도감, 하단 둥근 반투명 메인 액션. 아이보리 rgba(255,255,255,.85), 부드러운 그림자, 둥근 폰트.
- Lv1~3 작은 기본집·화단; Lv4~7 목장/동물/울타리; Lv8+ 바닷가/낚시·배 체험. 그리드 배치/회전, 저장 보존.
- 지그재그·에이블리의 데일리 패션 감성을 독자적인 SD 의상으로 재해석: 파스텔 니트/크롭티/루즈핏 가디건/리본스커트/원피스/세트/스니커즈. 기존 피팅룸 프레임 유지, 실시간 미리보기·저장·불러오기·상점 연결. 타사 로고/의상 도안 복제 금지.
- Idle→Walk→상호작용 부드러운 전환, 가감속 이동·도착 시 작은 바운스. 모션 감소 설정 존중.

재화는 사용자의 기존 진행을 보존하기 위해 조개를 유지한다. XP는 돌봄 활동의 기록이며 유료 섬 레벨과 별도 성장 수치로 표시한다. 미구현/미검증 기능을 완료로 표시하지 않는다.
