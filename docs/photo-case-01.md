# 第一依頼 / 빈자리의 주인 · v0.13.0

사진관 의뢰 퍼즐의 첫 플레이 가능한 실험. `photo-case.html` 또는 `?mode=case`로 진입. 기존 서울/도쿄/legacy와 모든 저장 키 유지. 새 저장 `afterlight-case-01-v1`.

하루의 부탁으로 철거 전 미나미 사진관을 촬영한다. 옛 사진에는 두 의자, 지금은 하나. 선반 기준으로 반투명 사진을 맞추고, 사진 뒷면/의자 아래 편지/빛이 비추는 바닥 자국을 모아 손님들을 위한 빈자리였음을 추론한다. 손님을 그리워하는 좌석 또는 새 작업실로 향하는 창가 구도를 골라 직접 셔터를 누른다. 사진과 하루의 답장은 선택에 따라 달라지고 사진책 JPG를 저장할 수 있다.

직접 의자 드래그와 사진 드래그, 같은 효과의 버튼 및 키보드 슬라이더, 무료 3단계 힌트, 기록, 포커스 유지/대화창 포커스 순환, 모션 감소, 자동 저장과 손상 데이터 복원. 재촬영은 증거를 보존하며 구도만 다시 선택한다. 다음 의뢰는 예고만 있고 실제 플레이는 준비 중임을 표시한다.

기존 도쿄 배경과 서울 의자 원화를 사용하는 소규모 프로토타입이다. 새로운 원화, 상용 결제/계정, 분석 수집, 모바일 실기기 검증은 이번 범위가 아니다. 신규 의뢰를 기존 챕터로 잘못 저장하지 않으며 앱 밖에 메시지를 보내지 않는다. 첫 사용자 반응 전 긴 분량을 약속하지 않는다.

검증: 엔진 정상/역순 조사, 두 촬영 분기와 저장 복원, 선행 조건, 오답 비소모, 손상된 저장/비정상 좌표, 힌트 상태. 브라우저 검증과 배포 결과는 UPDATE_LOG 및 release-state의 실제 기록을 따른다.
