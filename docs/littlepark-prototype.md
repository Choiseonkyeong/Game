# 모모의 작은 정원 — 첫 체험판

사용자 방향: 미니파크 꾸미기와 동식물 키우기. 퍼즐 중심 사진관은 보존하고 별도 제품 가설을 검증한다.

진입 dist/littlepark/index.html → park.js?v=2 → core.js?v=2. 직접 작성 SVG 정원/가구10종, 식물3종(데이지/튤립/라벤더), 개화120초와 물주기40초 보너스/8초 쿨다운. 꽃+물이 담긴 그릇에 고양이 방문, 벤치/방석 휴식, 쓰다듬기15초 쿨다운/친밀도10. 자동 저장 키 suming-littlepark-v1. 심은 화분 보관 거부, 이동 가능. 미접속 성장/시듦 없음. 전 가구 무료, 종류별 배치 한도. 친구·아바타·온라인·결제 없음.

핵심 가설: 사물 배치에 반응하는 동물과 자라는 식물이 꾸미기 동기를 만든다. 현재 고양이는 조건에 따른 위치/표정 변화이며 길찾기·자율 행동 AI는 아니다. 실제 장기 재미·모바일 입력 검증 필요.

검사70개, 공개 버전 actual browser 검수 범위는 UPDATE_LOG 및 release-state littlepark_release 참조. 390px helper는 QA만 사용하며 전달 URL은 정원 본체다.
