# 포근섬 사람·동물 스프라이트

## 현재 등록

- 사람 플레이어: 이전 여자·남자 디자인의 4방향×6프레임. 여자(긴 갈색 머리, 카키 재킷, 갈색 치마, 흰 신발, 갈색 가방), 남자(검은 머리, 흰 셔츠, 검정 바지, 흰 신발). 옷장에서 선택하고 별도 저장 키로 유지한다.
- 작아진 여자 머리 후보는 미사용. 기존 얼굴·헤어·의상을 보존하고 렌더러에서 목 기준 1.12 확대하여 큰 머리 비율로 보정한다. 신체·발 접점은 그대로다.
- 동물·색상 변형 86개. 고슴도치는 hedgehog 하나, 중복 porcupine 제외. 물개는 대화에서 처음 만든 원본 프레임을 사용한다. 말티즈, 푸들3색, 포메라니안, 시츄, 비숑, 치와와, 닥스훈트, 리트리버, 코기, 시바, 고양이5색과 햄스터·기니피그 포함.
- art/animals/catalog.json이 실제 목록이다. 개별 투명 WebP 경로, 행·열, 발 접점, FPS를 등록했다. 그림 원본은 별도 게임용 파일이며 개인 사진/문서는 공개하지 않는다.
- 동물 시트: 768×512, 셀128×128, 정면/뒷면/좌측/우측4행, 각6열(대기0, 걷기1~5), 발 접점64,116. 푸들3색은768×128 특수 포즈 시트 추가: 앉기/눈감기/엎드리기/낮잠/앞발인사/꼬리흔들기.
- 사람 시트: 768×768, 셀128×192, 같은4방향6열, 발 접점64,180. 디자인을 게임용으로 전개한 신규 프레임이며 기존 인물 디자인을 유지한다.

## 게임 연결

기존 island.js → human-sprites.js, animal-visitors.js. 기존 정원/진행/옷장 저장을 보존한다. 사람 선택은 pogeun-human-choice-v1에 저장한다. 기존 슬롯별 옷장 코디는 별도 선택으로 유지된다.

최대 동물 한 마리가 약14초 후 등장 → 기존 route로 가구 회피 → 약12초 휴식 → 퇴장 → 다음 방문. 대화창/꾸미기/돌봄 중 일시 정지한다. 푸들은 쉴 때 특수 포즈, 인사 때 앞발 인사. 다른 동물은 기본 대기·이동만 제공한다.

sprite-playground/index.html은 Canvas+순수JS 이동 확인 화면이다. 방향키/WASD, 4/8방향 선택, 대각선 속도 정규화, 키 해제 시 현재 방향 열0 정지, 터치 버튼/목적지 이동, 마젠타 크로마키와 imageSmoothingEnabled=false, image-rendering:pixelated를 제공한다. 실제 게임 리소스는 외부 개별 파일로 읽는다.

## 확장과 그래픽 기준

512×768 부위별 아트와 관절·슬롯은 docs/pogeun-art-spec.md 및 기존 rig.js가 기준이다. 향후 옷/신발/가방/소품/헤어/모자는 독립 레이어와 관절 기준에 맞춰 제작한다. 현재 새 남녀의 기본 디자인은 전체 프레임 시트이며, 다양한 옷 조합이 이미 구현됐다는 뜻은 아니다. 기존 컷아웃 리그와 의상 데이터는 보존했다.

이번 배포는 이전에 검수된 섬 배경·소품·좌표와 따뜻한 아트 기준을 보존한다. 전체 배경/소품을 새로 재제작한 버전은 아니다. 생성형 동물의 모든 방향/보행이 상용 수준으로 검수됐다는 주장은 하지 않는다. 사람 앉기·물주기 별도 프레임, 온라인 친구/채팅, 실제 휴대폰 터치 검수는 미완료다.
