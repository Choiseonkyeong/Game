# 포근섬 — 사람 아바타와 꾸미는 섬

사용자 방향: 퍼피레드의 미니파크·코디와 동식물 키우기, 동물의 숲처럼 작은 생활이 쌓이는 공간. 특정 IP의 캐릭터나 이름/자산을 복제하지 않고 독자 제품을 구성한다.

## 분석 및 선택

1. 첫 화면의 주인공은 사람이다. 꾸민 옷이 산책/돌봄/앉기에서 그대로 보이도록 단일 아바타 렌더러를 사용한다.
2. 꾸미기는 정해진 정답이 없어야 한다. 가구10종을 무료로 놓고 옮기며 회전한다. 섬 밖/집/다른 물건/아바타 위치는 막고 출구를 남긴다.
3. 식물/모모/사과/휴식이 짧은 생활 동기를 준다. 상시 접속 의무나 시드는 패널티는 없다.
4. 코디와 배치가 기념사진에 함께 남아 자기 표현으로 연결된다. 이번은 유료화 검증이 아닌 플레이 가능한 제품 원형이며 실결제/온라인 기능은 없다.

## 구현

- dist/island/index.html → island.js → core.js / avatar.js. 독립 저장키 suming-cozy-island-v1. 이전 정원/사진관 저장과 섞지 않는다.
- 아바타: 피부3/헤어4/머리색4/상의6/하의4/신발4/모자4/소품4. 모든 기본 코디 무료. 슬롯ID 검증과 코디4개 저장/불러오기. 아바타는 교체 가능한 SVG 벡터 레이어/관절 변환 기반2.5D이며 3D 메시/상용 스키닝 시스템은 아니다.
- 세계: 직접 작성 곡선 해안/모래/잔디/선착장, 기존 독자 입체 원화 아틀라스를 상대경로로 재사용. 카메라 확대1~1.45배. 기존 섬 자료를 이름만 바꾸는 복사 작업이 아니다.
- 생활: 잔디 탭→경로로 걷기. 물건을 누르고 행동→가장 가까운 인접칸 이동→물주기/심기/수확/앉기 실행. 꽃90초/물주기30초 가속·7초간격, 사과60초간격, 모모10초간격 친밀도. 모모는 경로·자세 전환.
- 사진: 현재 SVG와 같은 출처 이미지 원화를 데이터로 포함해 CanvasPNG 생성, 다운로드 버튼 제공. 별도 외부 촬영/업로드 없음.
- 초기 구성은 집·벤치·화분2·사과나무·물그릇·연못·디딤돌, 나머지는 무료 주머니. 기본 앱인 척 결제창을 만들지 않는다.

## 검증

자동 검사는 코디 슬롯/저장 독립성, 경로/거리, 식물과 쿨다운, 가구 충돌·집·해안·출구, 모든 코디의 행동 렌더링, 잘못된 저장 복원을 포함한다. 실제 브라우저 및 최종 소스/배포는 UPDATE_LOG와 release-state를 따른다. 실제 아이폰 터치·장기 재미·사업성·앱스토어 출시는 검증하지 않은 상태다.

## 다음 제품 검증

처음 보는 사람이 첫 코디를 만들고 걸어가 돌보는 데 도움이 필요한지, 꾸민 섬을 다시 보고 싶은지, 코디·가구를 수집하고 싶은지 관찰한다. 실시간 친구 방문과 상용 결제/계정/멀티디바이스 저장은 이 행동이 유효한 뒤 설계한다.
