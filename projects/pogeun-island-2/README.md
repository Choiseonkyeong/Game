파스텔 라이프 시뮬레이션 앱. 의상 PNG와 상품 아이콘을 포함한 현재 제작 버전입니다.

`dist/index.html`을 열면 실행됩니다. 옷장에서 상의·하의·아우터·소품·모자를 고르면 섬과 피팅 화면에 함께 반영됩니다. 원본 캐릭터 위에 덧입히며 몸체/헤어 분리는 포함하지 않습니다. 기존 코디·재화 저장 키를 유지합니다.

검증: `node --test tests/*.test.cjs`. 실제 모바일 시각·터치 검수는 미실시입니다.

의상: `dist/images/`, 상품 아이콘: `dist/images/icons/`. 도형 기반 원본 의상은 `tools/make-clothing.py`로 제작했습니다. 일러스트 가디건은 ImageGen으로 제작했으며 `sprite-config.js`에서 공통 좌표를 보정합니다.

# 포근섬 메인 화면 프로토타입

`dist/index.html`을 브라우저로 열면 실행됩니다. 설치나 빌드, 인터넷 연결이 필요하지 않습니다.

## 파일
- `dist/index.html`: 16:9 화면 및 HUD, 접근성 레이블, 팝업 구조
- `dist/style.css`: 파스텔 젤리 글래스 테마, 화면 크기별 UI
- `dist/app.js`: Canvas 임시 지형, 이동, 수확, 메뉴 상태

## 조작
- 빈 땅 클릭 / WASD / 방향키: 위치 마커 이동
- 텃밭 버튼: 당근 3회 수확, 매회 50 조개 지급
- 숫자 1–7: 하단 메뉴
- Esc: 팝업 닫기

## 범위
캐릭터와 이미지 소스는 새로 제작하거나 수정하지 않았습니다. 배경은 Canvas 도형으로 그린 임시 지형입니다. 캐릭터는 임시 피팅 레이어로 표시합니다. 실제 스프라이트는 `dist/wardrobe.js`의 아이템별 `src`에 연결하세요. `state.player`가 캐릭터의 월드 좌표이며, 캔버스 기준 해상도는 1600 × 900입니다.

향후 레이어 렌더 순서: 몸체 → 헤어 → 하의 → 상의 → 아우터 → 가방/소품 → 모자.

옷장은 레이어별 실시간 착용과 미착용, 기본 코디 리셋, 3개 코디 슬롯 저장·불러오기를 지원합니다. 공방, 부티크, 장터, 꾸미기는 확장용 팝업입니다. 재화·수확은 메모리 상태입니다. 현재 착용과 저장 코디는 브라우저 localStorage에 보관됩니다. 저장소 접근이 차단되면 세션 내에서 작동하며 저장 실패를 알립니다. 시간·날짜는 샘플 표시입니다. 효과음 버튼은 확인용 짧은 소리를 재생합니다.

작은 화면에서도 16:9를 유지하며 최소 580px 너비를 사용합니다. 필요하면 가로 스크롤할 수 있습니다.

## 검증
`node --check dist/app.js`로 JavaScript 구문을 검사했습니다. 이 환경에서는 브라우저 시각 검증을 수행하지 못했습니다.


## 1단계: 레이어드 옷장
- `dist/wardrobe.js`: 아이템 카탈로그, 공통 합성 렌더러, 착용 상태, 저장 데이터 검증, 옷장 UI
- 렌더 순서: 몸체 → 헤어 → 하의 → 상의 → 오픈형 아우터 → 소품 → 모자
- 모든 PNG는 **투명 배경과 같은 크기·원점·캐릭터 위치**를 사용해야 합니다. 현재 공통 프레임은 240×320입니다. 다른 해상도 이미지도 같은 비율·등록 위치라면 프레임에 맞춰 표시됩니다.
- `items`에 고유 `id`, `slot`, `name`, `src`로 등록합니다. 예: `{id:'top-oat', slot:'top', name:'오트밀 스웨트셔츠', src:'assets/top-oat.png'}`. 기존 아이템 경로만 교체하면 저장 코디 ID도 유지됩니다.
- 초기 SVG는 기능 확인용 피팅 가이드이며 첨부한 캐릭터 원화를 변형하지 않았습니다. 실제 이미지가 로드되지 않으면 오류를 표시하고 해당 레이어를 생략합니다.
- 코디 저장은 해당 슬롯을 덮어씁니다. 저장은 이 브라우저와 사이트 주소에 한정되며 계정 간 동기화는 하지 않습니다.
- 검증: `node tests/wardrobe.test.cjs`. 레이어 합성 순서, 착용 변경, 저장 복사, 새 인스턴스 복원, 리셋 시 보관함 유지, 손상 데이터 및 저장소 차단을 검사합니다. 실제 브라우저 시각 검증은 아직 수행하지 못했습니다.

## 2단계: 농장·채집·낚시·재화
- `dist/economy.js`: 검증된 저장 상태와 심기/성장/수확/보상/낚시 판정. `dist/life-ui.js`: 밭 버튼, 씨앗 선택, 곤충 이동, 낚시 타이밍 UI, 가방 갱신.
- 15개 밭 칸을 각각 클릭해서 심거나 수확합니다. 씨앗은 심는 순간 구매합니다. 당근: 10조개, 15초, 수확 시 당근 1개와 55조개. 목화: 20조개, 30초, 수확 시 폭신목화 원단 재료 1개.
- 나비는 15조개, 잠자리는 25조개와 해당 곤충 1마리를 줍니다. 잡은 개체는 12초 뒤 다시 출현합니다.
- 바닷가 낚시 버튼 → 던지기 → 8초 안에 초록 구간에서 낚아채기. 성공 시 25% 확률로 보물상자 1개, 나머지는 80조개. 실패·시간 초과·닫기에는 보상이 없습니다. 보물상자는 현재 보관 아이템이며 열기 기능은 후속 단계입니다.
- 상단 조개, 가방, 당근 퀘스트는 같은 경제 상태를 사용합니다. 조개·재료·누적 수확·밭 심기 시각은 `pogeun.economy.v1`에 저장합니다. 새로고침해도 성장 시간이 이어집니다. 시스템 시계에 기반한 브라우저 로컬 프로토타입이며 서버 검증은 없습니다. 기존 1단계 코디 저장은 별도 키로 유지됩니다.
- `node tests/economy.test.cjs`: 심기 비용, 성장 시각, 재접속 복원, 중복 수확 방지, 재료·곤충 보상, 낚시 성공/실패/취소/제한시간, 저장 및 잘못된 데이터 검증.
- 현재 재화와 수확도 저장되므로 위 초기 프로토타입의 메모리 상태 설명을 대체합니다. 실제 브라우저 시각·터치 검증은 미실시입니다.

## 3단계: 부티크·의상 공방
- 부티크: 전체/꾸안꾸/러블리 탭, 아이템 가격, 장바구니 추가·제거·합계, 일괄 구매. 장바구니는 결제 전에는 재화를 사용하지 않으며 창을 닫아도 이번 방문 동안 유지됩니다. 중복 의상은 구매할 수 없습니다.
- 기본 제작: 폭신목화 2개 + 100조개 → 폭신 코튼 블라우스.
- 유니크 합성: 폭신목화 3개 + 달빛 마법 가루 1개 + 200조개 → 달빛 별무리 블라우스. 재료 선택은 명시된 고정 제작법으로 제공합니다. 성공률 100%이며 의상별 한 번 제작할 수 있습니다.
- 당근 누적 3개 수확 후 부탁 공책이나 공방에서 달빛 마법 가루 1개를 한 번 수령할 수 있습니다. 퀘스트 보상 버튼을 여러 번 눌러도 중복 지급하지 않습니다.
- 구매·제작 후 옷장의 해당 분류에 의상이 추가됩니다. 유니크 의상 착용 시 옷장 미리보기와 섬 아바타에 Canvas 파티클이 표시됩니다. 합성 완료 시 카드에도 빛 효과가 나타납니다.
- `FashionCatalog` (`economy.js`): 상품 가격, 제작법, 슬롯, 유니크 여부. `fashion-ui.js`: 상점·공방 UI. `game-state.js`: 경제 상태 초기화. 기존 스크립트 로드 순서를 유지하세요.
- 상품 이미지는 기존 임시 피팅 가이드에서 파생된 색상 샘플입니다. 완성 스프라이트 연결 시 `wardrobe.js`의 카탈로그 확장 부분에서 `src`를 해당 투명 PNG 경로로 지정하세요. 외부 상점·브랜드 사이트 코드를 사용하지 않습니다.
- 보유 의상·퀘스트 수령·소모 재화는 경제 저장 키에 함께 기록됩니다. 기존 저장 데이터에는 새 필드의 기본값을 적용합니다. 옷장 저장은 기존 키를 유지합니다. 브라우저 저장이 차단되면 세션 내에서만 유지되고 완료 안내에 저장 불가를 표시합니다.
- 검증: `node tests/fashion.test.cjs`. 일괄 결제, 부족 재화·재료 무차감, 중복 구매·제작·보상 차단, 제작 비용, 유니크 획득, 구매 의상 착용과 새로고침 복원을 검사합니다. 브라우저 시각 검증은 미실시입니다.

## 4단계: 플리마켓·후기 공책·하우징·스카이 타워

### 장터
하단 ‘장터’ 또는 숫자 6으로 엽니다. 이 단계는 **브라우저 로컬의 가상 주민 장터**입니다. 다른 실제 사용자와 거래하거나 공유하지 않습니다.

- 이웃 가판대: 모리·나리의 상품을 조개로 구매합니다. 동일한 가판대 물건은 한 번만 구매할 수 있으며 가방에 즉시 들어옵니다.
- 나의 무인 가판대: 작물·목화·곤충·보물상자를 수량 1–99개, 묶음 가격 1–99,999조개로 진열합니다. 원단 합성용 퀘스트 가루와 의상은 현재 거래 대상에서 제외됩니다.
- 진열한 물건은 가방에서 차감되어 보관됩니다. 20초가 지나면 연습 주민이 구매합니다. 미판매 물건 회수, 판매 대금 직접 정산을 지원합니다. 미정산을 포함해 최대 6개 진열할 수 있습니다.
- 창을 닫거나 새로고침해도 진열 시각이 유지됩니다. 다음 실행 시에도 경과 시간을 계산해 판매를 처리합니다. 회수·정산·재구매를 중복 실행해도 추가 지급하지 않습니다.

### 아날로그 후기 공책
완료된 구매 거래마다 판매자에게 칭찬 도장 하나와 1–200자 후기를 남깁니다. 줄노트·제본·도장·손글씨 느낌의 UI이며, 텍스트를 입력하는 방식입니다. 펜 필기 입력 기능은 포함하지 않습니다.

- 판매자별 공책, 완료 거래 선택, 도장 3종, 후기 저장, 도장 누적 개수와 칭호를 표시합니다.
- 본인 판매에 스스로 후기를 쓰거나 같은 거래에 중복 후기를 남길 수 없습니다.
- 내 가판대의 자동 판매에는 ‘연습 주민’이라고 표시된 NPC 후기가 자동으로 남습니다.
- 사용자 후기는 HTML로 실행되지 않도록 이스케이프해 표시합니다.

### 하우징과 랜드마크
하단 ‘꾸미기’/숫자 7 또는 집 이름 버튼을 누릅니다.

- 마법사의 방: 별무리 러그, 달빛 창문, 책장과 서재 테이블.
- 카페 테라스: 햇살 창문, 카페 카운터, 테이블과 화분.
- 선택 시 즉시 방 미리보기를 갱신하고 ‘이 테마로 꾸미기’로 적용합니다. 테마와 집 이름을 저장합니다. 가구 개별 자유 배치는 후속 확장 항목입니다.
- 섬의 스카이 타워 이름 버튼, 화면 하단 중앙 항공 뷰 버튼, 하우징의 전망대 버튼으로 항공 뷰에 진입합니다. 탑·집·텃밭·광장·바닷가를 내려다보는 전용 Canvas 장면을 표시합니다.
- ‘앞마당으로 내려가기’로 이전 위치에 복귀합니다. 항공 뷰에서는 일반 이동과 밭·곤충 조작을 중지합니다. 뷰 상태도 저장합니다.

### 파일과 검증
- `community-ui.js`: 가판대, 거래 내역, 후기 공책.
- `housing-ui.js`: 테마 미리보기, 랜드마크 렌더, 항공 뷰.
- `economy.js`: 기존 재화 저장에 장터 거래·후기·하우징 상태를 통합. 이전 버전 저장 필드는 유지하고 새 필드는 기본값으로 보완합니다.
- `node tests/community.test.cjs`: 구매 차감, 물건 보관·회수, 오프라인 판매, 중복 정산 차단, 후기 자격·중복·본인 후기 차단, 테마와 뷰 저장 복원, 이전 데이터 호환.
- 기존 경제·옷장·부티크/공방 테스트도 통과했습니다. 브라우저 시각 검증은 수행하지 못했습니다.

## 실제 캐릭터 이미지 연결 (최신)

[SPRITES.md](./SPRITES.md)에 경로 표, z-index, 공통 프레임 규격, CSS 코드, 위치 보정 방법을 정리했습니다. `dist/sprite-config.js`가 모든 캐릭터 이미지 경로와 위치의 기준입니다. 이 항목은 위의 임시 SVG·마네킹 연결 안내를 대체합니다.

첨부 원본 JPG가 이미 포함되어 게임과 옷장에 표시됩니다. 분리된 PNG는 아직 없으므로 `body.png`가 준비되기 전에는 한 장의 완성 원본으로 표시합니다. 투명한 PNG 레이어가 준비되면 분리 모드로 전환하고, 코디 변경을 반영합니다. 원본 JPG의 흰 배경은 제거하지 않았습니다.
