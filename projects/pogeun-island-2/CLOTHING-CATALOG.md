# 옷장·부티크 아이템 카탈로그

사용자가 전달한 목록의 11개 아이템은 `dist/clothing-items.js`에 등록했습니다. 순수 JSON은 `dist/clothing-items.json`에 있습니다. 각 항목은 id/name/category/price/iconImg/layerImg를 가집니다.

- 상의: 오트밀 스웨트셔츠 0, 딸기 스트라이프 티 150, 파스텔핑크 레이스 블라우스 200, 포근한 오프숄더 베이지 니트 250.
- 하의: 데님 롤업 반바지 0, 화이트 티어드 롱스커트 200, 체크 플리츠 미니스커트 180.
- 아우터: 클래식 베이지 코트 350, 보송보송 아이보리 가디건 300.
- 모자: 리본 레이스 헤어밴드 120.
- 소품: 달빛 반짝 요정 날개 500.

카드 렌더링은 기존 `wardrobe.js`와 `fashion-ui.js`에 연결했습니다. 기본 상·하의는 초기 코디로 선택하며 무료입니다. 옷장 미보유 카드에는 구매 가격을 표시하고, 클릭하면 해당 부티크 탭을 엽니다. 부티크의 장바구니에서 결제하면 소유권을 얻습니다. 이후 옷장 카드 또는 부티크의 '지금 입어 보기'가 `Wardrobe.equip(id)`를 호출합니다.

기존 의상과 공방 제작법은 보존했습니다. 기존 버전에서 무료였던 딸기 스트라이프 티는 이전 저장 사용자가 잃지 않도록 보유권을 이전합니다. 새 게임에서는 지정된 150조개 가격을 적용합니다.

의상 이미지는 별도 제작하지 않았습니다. 미리보기 파일이 없는 카드는 '이미지 준비 중'으로 표시합니다. 코디 선택 상태는 즉시 저장하지만 실제 아바타 모양은 해당 layerImg PNG가 있어야 바뀝니다. 완성 캐릭터 모드에서는 새 의상을 위에 덮으며 기존 옷 자체를 지우지는 않습니다. 모든 레이어는 1230×1278 공통 프레임에 정렬해야 합니다.

JSON만 바꾸어도 자동 반영되는 구조는 아닙니다. 런타임의 기준은 clothing-items.js이며 JSON은 공유용 사본입니다.

검증: `node tests/catalog.test.cjs` 및 기존 경제·옷장·스프라이트·상점·장터 테스트. 브라우저 시각 검증은 미실시입니다.
